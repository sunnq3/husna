# Husna – web projects

One folder per project. Files are served by GitHub Pages at
https://sunnq3.github.io/husna/<folder>/<file>

- guest-hub/ — Beach & Beyond 10 guest hub (hub.css, hub.js; hub-wordpress.html is what gets pasted into the Elementor HTML widget). The Excursions panel is built by hub.js from CONFIG.excursions, with photos in guest-hub/img/, so it needs no WordPress change.
- bb10_itinerary_puntacana_2026/ — Beach & Beyond 10 itinerary (content in data/*.json; itinerary-wordpress.html is what gets pasted into the Elementor HTML widget)
- wcg2027-guest-hub/ — Winter Classic Getaway 2027 guest hub (same architecture as guest-hub, winter indigo/ice palette; all photos live in wcg2027-guest-hub/img/ on GitHub Pages, so nothing needs uploading to WordPress). Emails, contacts and the packing checklist are driven by CONFIG in hub.js; the Itinerary button enables itself once CONFIG.itinerary has a URL.
